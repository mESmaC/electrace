# Logo
The horizontal app-header lockup: the brand mark plus the "Electrace" wordmark and a code caret. Used in the app header and anywhere the full logo is needed.

**When to use:** When you need the complete wordmark lockup. For an icon-only mark, use LogoMark instead.

**Props:**
- `className` — `string` — sizes the lockup via font-size (e.g. `text-[17px]`); the mark scales with the text. Defaults to `""`.

**Example:**
```tsx
import { Logo } from "@electrace/ui";
<Logo className="text-[17px]" />
```
