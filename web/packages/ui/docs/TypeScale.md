# TypeScale
A reference card showing the Electrace type scale: Inter for UI (font-sans) and JetBrains Mono for values, nets and specs (font-mono).

**When to use:** When choosing a text size/weight/family — display, heading, body, label, value or net — to stay on-brand. Numbers and nets are always monospace.

**Props:** None — self-contained; renders fully populated from internal state. Drop it in.

**Example:**
```tsx
import { TypeScale } from "@electrace/ui";
<TypeScale />
```
