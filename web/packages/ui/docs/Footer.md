# Footer
The site footer — the Electrace wordmark, a short tagline, and grouped link columns (product, resources, legal). Used at the bottom of every marketing/app page.

**When to use:** As the page footer (it's already included by AppShell). Renders statically.

**Props:** None.

**Example:**
```tsx
import { Footer } from "@electrace/ui";

<Footer />
```
