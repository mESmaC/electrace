# LogoMark
The icon-only Electrace brand mark: a "C" ring with a resistor trace and net terminals through it. Themed to the current palette. Used as a favicon-style mark or inside the full Logo lockup.

**When to use:** When you need just the symbol without the wordmark — e.g. tight headers, avatars or loading states.

**Props:**
- `className` — `string` — applied to the `<svg>` to size/position it (e.g. `h-6 w-auto`). Defaults to `""`.

**Example:**
```tsx
import { LogoMark } from "@electrace/ui";
<LogoMark className="h-6 w-auto" />
```
