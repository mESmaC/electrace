# Dashboard
The projects dashboard — the design grid a user lands on. Inside AppShell: a heading + "New design"
action and a responsive grid of design cards, each with a glyph, name, spec line (monospace), and its
lint status (SevChip).

**When to use:** As the projects/home screen, or as the pattern for any card-grid page.

**Props:** None (carries demo data).

**Example:**
```tsx
import { Dashboard } from "@electrace/ui";
<Dashboard />
```
