# ColorTokens
A reference card that renders the real Electrace color tokens grid — semantic surfaces/borders/text plus theme-constant brand & status colors — so the design system can be seen and named.

**When to use:** When documenting the palette or picking the right token/Tailwind utility for a surface, border, text or accent.

**Props:** None — self-contained; renders fully populated from internal state. Drop it in.

**Example:**
```tsx
import { ColorTokens } from "@electrace/ui";
<ColorTokens />
```
